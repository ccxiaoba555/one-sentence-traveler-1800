A tiny Python program that writes a single sentence explaining the modern internet to a time traveler from the year 1800 — a road of light joining every house on earth, so a letter you write reaches the far side of the world, and any book you ask for arrives, before the ink on your pen is dry — to `/output/entry.txt`. Every word in the sentence was already in use before 1800, and it names no feature list, only that one road.

## Run it

```sh
python3 main.py
```
